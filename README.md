# طلبات مسكوب · Maskob Orders

تطبيق لمتابعة الطلبات بين مستودع مسكوب والفروع، في صفحة واحدة (`index.html`).

## سير العمل
1. **الفرع** يدخل برمزه، يختار الأصناف بالكميات (توريد من المستودع أو إرجاع)، ويرسل الطلب.
2. **الإدارة** تراجع الكميات وتعتمد الطلب أو ترفضه.
3. **المستودع** يجهّز الطلب كقائمة مهام (علامة ✓ لكل صنف) ثم يرسله.
4. **الفرع** يستلم ويسجّل الكميات المستلمة والملاحظات، وتظهر الفروقات تلقائياً.

## المزايا
- رمز دخول خاص لكل فرع وللإدارة وللمستودع، تديره الإدارة من «الإعدادات».
- 4 لغات: العربية، English، বাংলা، اردو.
- توقع الطلب القادم لكل فرع واحتياج المستودع لـ 7 أيام (بعد 3 طلبات معتمدة).
- تقرير يومي للإدارة مع نسخه نصاً لواتساب.
- تصدير إكسل للطلبات والتقرير والتوقعات.
- قائمة أصناف مسكوب (حوالي 170 صنفاً في 14 فئة) من ملف طلب فرع القطيف.

## التشغيل
النسخة الفعلية المشتركة بين الفروع منشورة على Claude:
https://claude.ai/artifact/CwiBiX54ReNZ66NEpmfjts

البيانات المشتركة (الطلبات والرموز والفروع) محفوظة في قاعدة بيانات الصفحة المنشورة على Claude.
عند فتح `index.html` مباشرة من هذا المستودع أو من GitHub Pages يعمل التطبيق في **وضع تجريبي**:
البيانات تبقى على الجهاز نفسه فقط ولا تتشارك بين الفروع.

## الملفات
- `index.html` — التطبيق كاملاً (الواجهة، الأصناف، الترجمات، الشعار مضمّن).
- `maskob-wordmark.png` — شعار مسكوب (أبيض وبرتقالي على خلفية شفافة).
